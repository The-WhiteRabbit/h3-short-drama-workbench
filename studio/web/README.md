# Review Web UI

The final UI should be a fixed HTML application.

It should load:

- asset_manifest.json
- shot.json
- review_state.json

It should not embed production data.

File changes update the UI after refresh or watcher notification without generating a new HTML file.

Main panels:

- Episode script review
- Storyboard review
- Shot prompt editor
- Candidate video comparison
- Approval history
